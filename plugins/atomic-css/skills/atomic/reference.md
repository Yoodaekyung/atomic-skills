## 관계 선택자

| 형태 | 설명 |
| --- | --- |
| `child-<target>-<class>` | 결합자 ">" (child) — 단독 관계. 예: child-li-mt10px |
| `children-<target>-<class>` | 결합자 "(공백)" (children) — 단독 관계. 예: children-li-mt10px |
| `next-<target>-<class>` | 결합자 "+" (next) — 단독 관계. 예: next-li-mt10px |
| `siblings-<target>-<class>` | 결합자 "~" (siblings) — 단독 관계. 예: siblings-li-mt10px |
| `child-li-hover-<class>` | Emmet 체인: 결합자 뒤 요소에 의사클래스 귀속 → .x > li:hover{...} |
| `child-li-nth-child-2-<class>` | Emmet 체인 + nth: .x > li:nth-child(2){...} (리스트의 N번째) |
| `nth-child-2-child-li-<class>` | 선행 의사는 본인에 귀속: .x:nth-child(2) > li{...} |
| `<trigger>-hover-child-<target>-<class>` | 트리거형: .trigger:hover > target{...} (예: card-hover-child-img-ofc) |
| `child-ul-child-li-<class>` | 다중 체인: .x > ul > li{...} (결합자 반복) |
| `child-all-<class> / children-div-<class>` | target에 all → *(와일드카드). children는 공백 결합자(자손) |

## 구문 규칙

| 규칙 | 설명 |
| --- | --- |
| 네이밍 | CSS 속성+값의 앞글자 조합 (예: display:flex → df, justify-content:center → jcc) |
| 단위 규칙 | 20px 미만 → px (gap8px), 20px 이상 → rem (gap2rem = 20px, 1rem = 10px) |
| 간격 | 디자인 값 우선. 정해진 값이 없을 때 margin/padding/gap 등은 4의 배수 권장 (4, 8, 12, 16, 20, 24, 32...) |
| p = % | w50p → width: 50%, h100p → height: 100% |
| 하이픈(-) | 소수점: gap1-5rem → 1.5rem / 값 구분: gtc1fr-2fr → 1fr 2fr / 미디어: sm-dn / 의사클래스: hover-bg000000 |
| i 접미사 | !important 추가. 예: w100pxi → width: 100px !important |
| neg- 접두사 | 음수값. 허용: margin(+4방향), top/right/bottom/left, inset, letter-spacing, word-spacing, text-indent, outline-offset, grid-column-start/end, grid-row-start/end, scroll-margin(+4방향), z-index, order, transform. 예: neg-mt10px, neg-zi5, neg-tr45deg, neg-ttx50p, neg-in10px(inset), neg-gcs2. 그 외 속성은 원천 차단(neg-w100px 무효). 가상요소/의사클래스 조합: before-neg-mt10px, hover-neg-zi1 |
| 미디어 쿼리 | 프리픽스- + 클래스. 예: sm-dn → @media(max-width:768px){display:none} / 14개 브레이크포인트 |
| 의사 클래스 | 프리픽스- + 클래스. 예: hover-bgFFFFFF → :hover{background-color:#FFFFFF} / 39개 지원 (구조 의사클래스 first-child, last-child, only-child, first-of-type, last-of-type, only-of-type, root 포함) |
| nth 의사클래스 | 인자형 구조 의사클래스. nth-child/nth-last-child/nth-of-type/nth-last-of-type + -인자- + 클래스. 인자: 정수(2), odd, even, An(2n), An+B(2n1→2n+1). 예: nth-child-2-dn → :nth-child(2){display:none} / nth-child-odd-bg000000 → :nth-child(odd) / nth-child-2n1-mt10px → :nth-child(2n+1) |
| 관계 선택자 | 결합자 child(>)/children(공백)/next(+)/siblings(~). ①단독: child-li-mt10px → .x > li{...}. ②트리거형: card-hover-child-img-ofc → .card:hover > img{...}. ③Emmet 체인(좌→우): 결합자 뒤 요소에 의사클래스/nth 귀속. child-li-hover-dn → .x > li:hover / child-li-nth-child-2-dn → .x > li:nth-child(2) / 선행 의사는 본인: nth-child-2-child-li-dn → .x:nth-child(2) > li. 다중체인: child-ul-child-li-first-child-c000000. target에 all → *(와일드카드) |
| 의사 요소 | ::before, ::after 지원. 관계 선택자·nth와 조합 가능(순서: 의사클래스→의사요소). 예: child-li-hover-after-c000000 → .x > li:hover::after |
| Grid | gtc(columns)/gtr(rows) + 값. 예: gtc1fr-2fr → 1fr 2fr / gtcr3-1fr → repeat(3,1fr) / gtcrfit-minmax200px-1fr → repeat(auto-fit,minmax(200px,1fr)) |
| 색상 | c(color)/bg(background)/bc(border-color) + 6자리 HEX. 예: cFFFFFF / RGBA: c255-0-0-50 |
| 보더 | b + 크기 + 단위 + 스타일 + HEX. 예: b1pxsolidDDDDDD / 방향: bt(top), br(right), bb(bottom), bl(left) |
| 트랜지션 | t + 속성 + 시간 + 타이밍. 예: tall200msease / cubic-bezier: tall200mscb0-50-50-100 |
| 트랜스폼 | ttx/tty(translate), tr(rotate), ts(scale). 예: ttx10px, tr45deg, ts1-5 |
| 필터 | filter 접두사 + 함수약어. filterb(blur), filterbr(brightness), filterc(contrast), filterg(grayscale), filterhr(hue-rotate), filteri(invert), filtero(opacity), filters(sepia), filtersa(saturate), filterds(drop-shadow), filtern(none). 예: filterb5px, filterbr120p, filterhr90deg |
| 백드롭 필터 | bf 접두사 + 함수약어. bfb(blur), bfbr(brightness), bfc(contrast), bfg(grayscale), bfhr(hue-rotate), bfi(invert), bfo(opacity), bfs(sepia), bfsa(saturate), bfn(none). 예: bfb5px → backdrop-filter: blur(5px) |
| 그림자 | bs(box-shadow), ts(text-shadow) + X + Y + blur + spread + 색상. 예: bs2px4px10px0pxFF0000 |
| 종횡비 | ar + 비율. 예: ar16-9 → 16/9, ar1 → 1 |
| 줄 제한 | lc + 줄수 + 줄높이. 예: lc3-1-5rem → 3줄, line-height 1.5rem |
| CSS 변수 | 프리픽스--변수명 → var(--변수명). 모든 단위/색상 프리픽스 지원. 예: bg--box-color → background-color: var(--box-color) / 미디어(md-bg--x), 의사클래스(hover-bg--x), !important(bg--xi), before/after, 관계선택자 모두 조합 가능 |
